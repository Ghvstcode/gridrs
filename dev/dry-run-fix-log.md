Every task was implemented once by a separate agent given only its manifest prompt. These are the changes that exercise forced on the task set.

All existing dry-run implementations passed unchanged.

5. 0002 / 0104 / 0203 / 0204 (prompts silent, implementers guessed; all guesses happened to pass): added one sentence each stating the behaviour: round_to on non-finite input and on overflow; evaluator processes call arguments strictly left to right up to an oversized range; a non-finite count is #NUM!; INDEX checks both lower bounds before either upper bound. Added acceptance assertions for the 0104 and 0204 rules.
6. 0601-app (prompt silent, implementer guessed): Enter/Tab commit at the last row/column, and the End key in Normal mode, were unspecified. Prompt now says the post-commit move clamps at the sheet edge and End (and other Ctrl keys) are ignored; added an acceptance test at the sheet corner that also exercises 0x0 frames.
7. 0404 / 0403 (tests too loose): added kind_for_path cases for backslash separators and a bare .grid name, and a paste clipped at the last row. Existing implementations passed unchanged.
